# ファンファーレ音源について

このディレクトリには、ガチャでカードを獲得した際に再生されるファンファーレ音源を配置します。

## 必要な音源ファイル

以下のファイル名で音源を配置してください：

- `fanfare_ss.mp3` - SS賞用ファンファーレ（最高レア）
- `fanfare_s.mp3` - S賞用ファンファーレ（高レア）
- `fanfare_a.mp3` - A賞用ファンファーレ（中レア）
- `fanfare_b.mp3` - B賞用ファンファーレ（低レア）
- `fanfare_c.mp3` - C賞用ファンファーレ（通常）

または、全レアリティ共通の音源として：

- `fanfare.mp3` - 共通ファンファーレ（デフォルト）

## 音源の仕様

- **形式**: MP3
- **長さ**: 2〜5秒程度推奨
- **音量**: 適度な音量（大きすぎないこと）
- **ファイルサイズ**: 1MB以下推奨

## 音源が見つからない場合

音源ファイルが配置されていない場合、音が再生されません（エラーは発生しません）。

## 音源の入手方法

### 1. フリー音源サイト
- [効果音ラボ](https://soundeffect-lab.info/)
- [魔王魂](https://maou.audio/)
- [DOVA-SYNDROME](https://dova-s.jp/)

### 2. 自作
- GarageBandやAudacityなどの音楽制作ソフトで作成

### 3. AI生成
- Suno AIやMusicGenなどのAI音楽生成サービスを利用

## 例：効果音ラボからのダウンロード手順

1. https://soundeffect-lab.info/ にアクセス
2. 「ファンファーレ」「勝利」「成功」などのキーワードで検索
3. 気に入った音源をMP3形式でダウンロード
4. ファイル名を変更（例：`fanfare_ss.mp3`）
5. このディレクトリに配置

## 注意事項

- 音源の著作権・ライセンスを必ず確認してください
- 商用利用の場合は、ライセンスに注意してください
- 音量が大きすぎる場合は、音声編集ソフトで調整してください
