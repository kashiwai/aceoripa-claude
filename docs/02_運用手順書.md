# ACEORIPA 運用手順書

## 1. 環境構築手順

### 1.1 開発環境セットアップ
```bash
# リポジトリクローン
git clone [repository-url]
cd aceoripa-claude

# 依存関係インストール
npm install

# 環境変数設定
cp .env.example .env.local
# .env.localを編集して必要な値を設定

# 開発サーバー起動
npm run dev
```

### 1.2 本番環境構築（Netlify）
1. Netlifyダッシュボードにログイン
2. "New site from Git"でGitHub連携
3. ビルド設定:
   - Build command: `npm run build`
   - Publish directory: `.next`
4. 環境変数設定（Environment variables）
5. Deploy site

## 2. 日常運用手順

### 2.1 コンテンツ管理

#### ガチャ商品登録
1. 管理画面（/admin）にログイン
2. 「ガチャ管理」メニューを選択
3. 「新規作成」ボタンクリック
4. 必要情報を入力:
   - 商品名
   - 説明文
   - 価格（ポイント）
   - 販売期間
   - バナー画像URL
5. 「保存」をクリック

#### カード一括登録
1. 「カード管理」→「CSVアップロード」
2. CSVファイルを準備（テンプレート使用）
3. ファイルを選択してアップロード
4. プレビュー確認後「インポート実行」

### 2.2 ユーザー対応

#### お知らせ配信
1. 「お知らせ管理」メニュー
2. 「新規作成」をクリック
3. 内容入力:
   - タイトル
   - 本文
   - 種類（ニュース/メンテナンス/キャンペーン/重要）
   - ポップアップ表示設定
4. 「公開」ステータスで保存

#### ユーザー問い合わせ対応
1. 「ユーザー管理」でユーザー検索
2. 購入履歴・ガチャ履歴確認
3. 必要に応じてポイント調整

### 2.3 売上管理

#### 日次確認
1. 「ダッシュボード」で当日売上確認
2. 「決済管理」で詳細確認
3. 異常な取引がないかチェック

#### 月次レポート
1. 「レポート」→「月次売上」
2. 期間指定してエクスポート
3. 売上分析・KPI確認

## 3. メンテナンス手順

### 3.1 定期メンテナンス

#### 毎日
- サーバー稼働状況確認
- エラーログ確認
- 売上速報確認

#### 毎週
- データベースバックアップ確認
- 不要ログのクリーンアップ
- パフォーマンス指標確認

#### 毎月
- セキュリティアップデート適用
- 依存関係の更新
- 容量使用状況確認

### 3.2 緊急対応

#### サービス停止時
1. Netlifyステータス確認
2. Supabaseダッシュボード確認
3. エラーログ解析
4. 必要に応じてロールバック

#### 決済エラー時
1. GMO fincode管理画面確認
2. エラー内容の特定
3. 影響範囲の確認
4. ユーザーへの返金処理

## 4. バックアップ・リストア

### 4.1 バックアップ
- **データベース**: Supabase自動バックアップ（日次）
- **画像ファイル**: Supabase Storage自動バックアップ
- **コード**: GitHubリポジトリ

### 4.2 リストア手順
1. Supabaseダッシュボードからバックアップ選択
2. リストアポイント指定
3. リストア実行
4. 動作確認

## 5. 監視項目

### 5.1 システム監視
- **稼働率**: 99.9%以上を維持
- **レスポンス時間**: 3秒以内
- **エラー率**: 1%未満

### 5.2 ビジネス指標
- **DAU/MAU**: 日次/月次アクティブユーザー
- **課金率**: 課金ユーザー比率
- **ARPPU**: 課金ユーザーあたり売上

## 6. トラブルシューティング

### よくある問題と対処法

#### ログインできない
1. Supabase Authステータス確認
2. 環境変数の設定確認
3. ネットワーク接続確認

#### 決済が完了しない
1. GMO fincode APIステータス確認
2. 決済ログ確認
3. タイムアウト設定確認

#### 画像が表示されない
1. Supabase Storage確認
2. 画像URLの有効性確認
3. CORS設定確認
