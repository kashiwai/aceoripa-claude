# ガチャカードシステムの実装

## 概要
ガチャ詳細ページ（/gacha/[id]）におけるカード一覧表示機能の実装状況をまとめています。

## 現在の実装状況

### 1. カード一覧の表示
- ✅ 固定データからの表示（フォールバック用）
- ✅ Supabaseからのデータ取得対応
- ✅ レアリティごとのグループ化表示
- ✅ 各レアリティの確率表示
- ✅ カード画像の表示

### 2. データベース構造

#### pokemon_cardsテーブル
```sql
- id: UUID (主キー)
- card_name: VARCHAR(255) - カード名
- product_code: VARCHAR(100) - 商品コード（ユニーク）
- rarity: VARCHAR(10) - レアリティ（SS, S, A, B, C）
- image_url: TEXT - 画像URL
- market_price: INTEGER - 市場価格
- description: TEXT - 説明文
```

#### gacha_pokemon_poolsテーブル
```sql
- id: UUID (主キー)
- gacha_product_id: UUID - ガチャ商品ID
- pokemon_card_id: UUID - ポケモンカードID
- weight: INTEGER - 出現確率の重み
```

### 3. APIエンドポイント

#### GET /api/gacha/products/[id]/pool
ガチャIDに対応するカードプールを取得
- Supabaseから実際のデータを取得
- データがない場合はフォールバックデータを返却
- レアリティごとの確率を計算して返却

### 4. フロントエンド機能

#### カード一覧表示
- レアリティごとにグループ化して表示
- B, C, Dランクは「その他」として統合
- 各レアリティの確率をパーセンテージで表示
- カード画像をグリッド形式で表示

#### 期待値計算
- 10回ガチャの期待値を動的に計算
- 50回ガチャの期待値を動的に計算
- 実際の確率データに基づいた計算

## セットアップ手順

### 1. データベースの準備
```bash
# Supabaseのダッシュボードで以下のSQLを実行
# または、ローカル環境で実行
supabase/seed-gacha-pools.sql
```

### 2. 環境変数の設定
```env
NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
```

### 3. アプリケーションの起動
```bash
npm run dev
```

## 技術的な注意点

1. **確率計算**
   - weightの合計を100%として計算
   - 各レアリティの合計weightで確率を算出

2. **画像の最適化**
   - Next.js Imageコンポーネントを使用
   - unoptimizedフラグで外部画像も対応

3. **エラーハンドリング**
   - Supabase接続エラー時はフォールバックデータを使用
   - ユーザーには常にデータが表示される

4. **パフォーマンス**
   - APIレスポンスをキャッシュ可能
   - 画像の遅延読み込み対応
