# ACEORIPA AI自動生成ソリューション マニュアル

## 1. 概要

ACEORIPAのAI生成機能は、OpenAI API（GPT-4、DALL-E 3）を活用して、ガチャバナー、演出動画、カード画像などを自動生成する革新的なソリューションです。

## 2. AI生成機能一覧

### 2.1 利用可能な生成機能
- **ガチャバナー生成**: 1024×1024pxのバナー画像
- **演出動画生成**: ガチャ演出用のアニメーション
- **カード画像生成**: ポケモンカード風デザイン
- **3Dモデル生成**: 演出用3Dモデル
- **告知バナー生成**: お知らせ・キャンペーン用

## 3. バナー画像生成

### 3.1 アクセス方法
```
管理画面 → AI生成 → ガチャバナー生成
```

### 3.2 基本的な使い方
1. **生成タイプ選択**:
   - 新規ガチャバナー
   - 季節イベントバナー
   - コラボバナー
   - 限定セールバナー

2. **プロンプト入力**:
   ```
   例: ピカチュウの電撃が走る、黄色と黒を基調とした
   クールなガチャバナー。稲妻のエフェクトと
   「THUNDER SHOCK GACHA」のロゴを含む
   ```

3. **スタイル設定**:
   - **雰囲気**: クール/かわいい/迫力/高級感
   - **カラーテーマ**: 自動/指定色
   - **テキスト**: バナーに含めるテキスト

4. **生成実行**:
   - 「生成」ボタンをクリック
   - 4つのバリエーションが生成される
   - 気に入ったものを選択

### 3.3 高度な設定

#### プロンプトのコツ
```
良い例:
- 具体的な要素を指定
- 色や雰囲気を明確に
- ブランドイメージに合わせる

悪い例:
- 曖昧な指示
- 矛盾する要求
- 著作権侵害の可能性がある内容
```

#### スタイルプリセット
1. **DOPA風**: 赤と黒、ゲーミング風
2. **プレミアム**: 金色、高級感
3. **カジュアル**: ポップで親しみやすい
4. **和風**: 日本的な要素

## 4. 演出動画生成

### 4.1 動画タイプ
- **ノーマル演出**: 5秒、基本エフェクト
- **レア演出**: 8秒、特殊エフェクト
- **激レア演出**: 12秒、豪華エフェクト

### 4.2 生成手順
1. 演出レベルを選択
2. モーション設定:
   - 回転速度
   - 光の強さ
   - パーティクル量
3. BGM選択:
   - デフォルトBGM
   - カスタムアップロード
4. 「プレビュー生成」
5. 調整して「確定」

### 4.3 カスタマイズ
```javascript
// 演出パラメータ例
{
  "duration": 8000, // ミリ秒
  "effects": {
    "particles": true,
    "lightning": true,
    "shake": true
  },
  "colors": ["#FFD700", "#FF6B6B"],
  "intensity": 0.8
}
```

## 5. カード画像生成

### 5.1 用途
- テストカード作成
- プレースホルダー画像
- 特別企画カード

### 5.2 生成設定
1. **カードタイプ**:
   - ポケモンカード風
   - オリジナルデザイン
   - コラボデザイン

2. **要素指定**:
   - ポケモン名/キャラクター
   - タイプ（炎/水/草など）
   - レアリティ表記
   - 特殊効果

3. **デザイン調整**:
   - 背景パターン
   - ホログラム効果
   - 枠デザイン

## 6. 生成物の管理

### 6.1 保存と整理

- タグ付けで検索可能
- お気に入り機能

### 6.2 使用履歴
- どのガチャで使用されたか追跡
- パフォーマンス分析
- A/Bテスト結果

## 7. ベストプラクティス

### 7.1 効果的な活用方法
1. **季節性を意識**:
   - 春: 桜、パステルカラー
   - 夏: 海、鮮やかな色
   - 秋: 紅葉、温かい色
   - 冬: 雪、クールな色

2. **ターゲット層に合わせる**:
   - 若年層: ポップ、カラフル
   - 成人層: シック、高級感

3. **統一感を保つ**:
   - ブランドガイドライン遵守
   - シリーズで一貫性

### 7.2 注意事項
- 著作権に配慮
- 公序良俗に反しない内容
- 誤解を招く表現を避ける

## 8. トラブルシューティング

### 8.1 生成エラー時
1. プロンプトを簡潔に
2. 禁止ワードをチェック
3. API制限を確認

### 8.2 品質が低い場合
1. プロンプトを詳細に
2. スタイル設定を調整
3. 複数回生成して選択
