# Aceoripa オンラインガチャシステム 技術仕様書

## 1. プロジェクト概要

### 1.1 システム名
**Aceoripa（エースオリパ）** - ポケモンカード専用オンラインガチャサイト

### 1.2 コンセプト
市場カード戦略式を採用した、ポケモンカードコレクターのためのプレミアムオンラインガチャプラットフォーム。実物のトレーディングカードをデジタルガチャで獲得し、コレクションを楽しむサービス。

### 1.3 主要機能
- リアルタイムガチャシステム（感動的な演出付き）
- 市場カード戦略式利益管理システム
- 管理者向け高度な分析ツール
- PWA対応モバイルファースト設計
- AIを活用した価格最適化

## 2. 技術スタック

### 2.1 フロントエンド
- **フレームワーク**: Next.js 14（App Router）
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Hooks
- **アニメーション**: Framer Motion, Lottie
- **3D演出**: Three.js

### 2.2 バックエンド
- **APIルート**: Next.js API Routes
- **データベース**: Supabase（PostgreSQL）
- **認証**: Supabase Auth
- **ストレージ**: Supabase Storage
- **リアルタイム**: Supabase Realtime

### 2.3 決済システム
- **メイン決済**: Square
- **サブ決済**: Fincode（準備中）
- **ポイントシステム**: 独自実装

### 2.4 インフラ
- **ホスティング**: Netlify / Google Cloud Run
- **CDN**: Netlify Edge
- **モニタリング**: Google Analytics 4
- **プッシュ通知**: Web Push API

### 3.2 データベース設計

#### 主要テーブル
1. **users**: ユーザー情報
2. **pokemon_cards**: カードマスタデータ
3. **gacha_products**: ガチャ商品
4. **gacha_pokemon_pools**: ガチャ排出設定
5. **transactions**: 取引履歴
6. **user_cards**: ユーザー所持カード
7. **user_points**: ポイント残高

#### 特殊機能テーブル
- **market_strategy_calculations**: 市場カード戦略式計算履歴
- **price_monitoring_targets**: 価格監視設定
- **gacha_optimization_history**: AI最適化履歴

## 4. ガチャシステム詳細

### 4.1 ガチャ実行フロー
1. **認証確認**: ユーザーログイン状態チェック
2. **ポイント確認**: 残高確認・消費処理
3. **抽選処理**: 重み付き確率に基づくカード選出
4. **演出表示**: レアリティに応じた感動演出
5. **結果保存**: DBへの結果記録
6. **履歴更新**: ユーザーコレクション更新

### 4.2 確率制御システム
- **基本確率**: カードごとの重み設定
- **天井機能**: SS確定保証（利益率連動）
- **ピックアップ**: 特定カード確率UP
- **10連保証**: S以上確定

### 4.3 演出システム
