# システム操作マニュアル - Aceoripa System Operations Guide

## ⚠️ 重要な注意事項

### 本番環境での作業前に必ず確認
```markdown
❗ 以下の操作は本番データに直接影響します
□ バックアップを取得済みか確認
□ 作業時間帯は適切か（深夜推奨）
□ 影響範囲を把握しているか
□ ロールバック手順を理解しているか
□ 緊急連絡先を把握しているか
```

### 禁止事項
```markdown
🚫 以下の操作は絶対に行わないでください
- 本番DBでDROPコマンドの実行
- 認証なしでのadmin APIの公開
- 環境変数の直接コミット
- ユーザーパスワードの平文保存
- 本番環境でのテストデータ作成
```

## 1. 管理画面操作

### 1.1 ログイン手順

#### アクセスURL
```
本番環境: https://ace-oripa.com/admin
開発環境: http://localhost:3000/admin
```

#### ログイン情報
```yaml
Email: admin@aceoripa.com
Password: [環境変数ADMIN_PASSWORDを参照]

⚠️ 注意:
- パスワードは定期的に変更する
- 共有アカウントは使用しない
- 2段階認証を有効化する
```

#### ログイン手順
```markdown
1. 管理画面URLにアクセス
2. Email/Passwordを入力
3. 「ログイン」ボタンをクリック
4. ダッシュボードが表示されることを確認

❗ ログインできない場合:
- ブラウザのキャッシュをクリア
- シークレットモードで試行
- Supabase Dashboardで認証状態確認
```

## 2. ガチャ管理操作

### 2.1 新規ガチャ作成

#### Step 1: 基本情報入力
```markdown
必須項目（*印）:
- ガチャ名* : 全角30文字以内
- 説明文 : 全角200文字以内
- 単発価格* : 100-99999ポイント
- 10連価格 : 単発×10の95%推奨
- 総パック数* : 100-99999
- 販売期間 : 開始/終了日時

⚠️ 注意:
- 価格は後から変更不可
- 総パック数は増やすことのみ可能
```

#### Step 2: バナー画像設定
```markdown
画像仕様:
- 形式: JPG/PNG/WebP
- サイズ: 1920×1080px推奨
- 容量: 5MB以下

アップロード手順:
1. 「画像を選択」ボタンクリック
2. ファイル選択
3. プレビュー確認
4. 「アップロード」実行

❗ エラーが出る場合:
- ファイルサイズを確認
- 画像形式を確認
- ネットワーク接続確認
```

#### Step 3: カードプール設定
```markdown
カード追加方法:
1. 「カード追加」ボタンクリック
2. カード一覧から選択（複数可）
3. 各カードの重み設定（1-9999）
4. 「確定」ボタンクリック

確率計算:
- 自動計算される確率を確認
- 合計が100%になることを確認
- SS/S級は合計5%以下推奨

⚠️ 最低20種類のカード登録必須
```

#### Step 4: DOPA設定
```javascript
// DOPA設定例
{
  "actual_return_rate": 0.70,    // 実質還元率
  "display_return_rate": 0.97,   // 体感還元率
  "explosion_ad_rate": 0.15,     // 爆アド率
  "point_return_distribution": {
    "low": 40,     // 低還元40%
    "mid": 30,     // 中還元30%
    "high": 20,    // 高還元20%
    "super": 10    // 超還元10%
  }
}

⚠️ 実質還元率70%を超えないこと
```

#### Step 5: 最終確認と公開
```markdown
確認項目:
□ 価格設定は適切か
□ カードプールは50種類以上か
□ 確率合計は100%か
□ 利益計算は黒字か
□ テスト実行済みか

公開手順:
1. 「プレビュー」で最終確認
2. 「下書き保存」または「公開」選択
3. 公開日時を設定（即時/予約）
4. 「実行」ボタンクリック

⚠️ 公開後の価格変更は不可
```

### 2.2 既存ガチャ編集

#### 編集可能項目
```markdown
✅ 変更可能:
- ガチャ名
- 説明文
- バナー画像
- 販売期間
- アクティブ状態
- 在庫追加（増加のみ）

❌ 変更不可:
- 価格
- カードプール（追加は可能）
- 確率（重み調整は可能）
```

#### 在庫追加手順
```markdown
1. ガチャ一覧から対象選択
2. 「編集」ボタンクリック
3. 「在庫管理」タブ選択
4. 追加数量入力（100単位推奨）
5. 「在庫追加」実行

⚠️ 在庫減少は不可（売れた分のみ減少）
```

### 2.3 ガチャ停止・削除

#### 一時停止
```markdown
停止手順:
1. ガチャ一覧から対象選択
2. 「アクティブ」トグルをOFF
3. 確認ダイアログで「停止」選択

影響:
- 新規購入不可
- 既存ユーザーの履歴は保持
- いつでも再開可能
```

#### 完全削除
```markdown
⚠️ 削除は原則禁止（以下の条件時のみ）
- 一度も購入されていない
- テストデータ
- 重大な設定ミス

削除手順:
1. バックアップ取得必須
2. 「削除」ボタンクリック（要管理者権限）
3. 確認コード入力
4. 最終確認で「削除実行」

❗ 削除後の復元は不可能
```

## 3. カード管理操作

### 3.1 カード登録

#### 個別登録
```markdown
必須項目:
- カード名*
- 商品コード*（ユニーク）
- レアリティ*（SS/S/A/B/C）
- カードタイプ*
  - physical: 物理カード
  - point_return: ポイント還元
- 市場価格

画像アップロード:
1. 300×400px推奨
2. 背景透過PNG推奨
3. 1MB以下

⚠️ 商品コードは変更不可
```

#### CSV一括登録
```csv
card_name,product_code,rarity,market_price,image_url
ピカチュウVMAX,PIKA-001,SS,50000,/images/cards/pika-001.jpg
リザードンGX,CHAR-001,S,30000,/images/cards/char-001.jpg
```

```markdown
インポート手順:
1. 「CSVインポート」ボタン
2. テンプレートダウンロード
3. データ入力
4. ファイル選択
5. プレビュー確認
6. 「インポート実行」

❗ エラー時の対処:
- 文字コードはUTF-8
- 改行コードはLF
- カンマ区切り厳守
```

### 3.2 価格更新

#### 手動更新
```markdown
1. カード一覧から対象選択
2. 「価格編集」クリック
3. 新価格入力
4. 「更新」実行

⚠️ ガチャ確率に影響する可能性
```

#### 自動価格取得
```markdown
設定手順:
1. 「価格監視設定」タブ
2. 監視対象カード選択
3. プラットフォーム選択
   - カードラッシュ
   - メルカリ
   - ヤフオク
4. 監視間隔設定（30分推奨）
5. アラート閾値設定（±20%）

⚠️ API制限に注意（100回/時）
```

## 5. 決済管理操作

### 5.1 決済履歴確認

#### 検索フィルター
```markdown
期間: 日付範囲指定
状態:
  - completed（完了）
  - pending（処理中）
  - failed（失敗）
  - refunded（返金済）
金額: 範囲指定
決済方法: Square/Fincode
```

### 5.2 返金処理

#### 返金手順
```markdown
1. 決済履歴から対象取引検索
2. 「詳細」ボタンクリック
3. 「返金」ボタン表示確認
4. 返金額入力（一部返金可）
5. 返金理由選択
6. 「返金実行」クリック

処理時間:
- Square: 即時〜3営業日
- Fincode: 即時〜5営業日

⚠️ 返金後のポイント回収必須
```

#### 返金できない場合
```markdown
以下の場合は返金不可:
- 購入から180日経過
- すでに全額返金済み
- チャージバック済み
- 決済プロバイダ側エラー

対処法:
- ポイント補償で対応
- 上位承認を取得
```

## 9. トラブルシューティング

### 9.1 よくある操作ミスと対処

| 操作ミス | 影響 | 対処法 |
|---------|------|--------|
| 誤って本番データ削除 | データ消失 | 即座にバックアップからリストア |
| 環境変数の誤設定 | サービス停止 | 前の値に戻してデプロイ |
| 誤った価格設定 | 売上損失 | ガチャ停止→新規作成 |
| 大量ポイント誤付与 | 経済バランス崩壊 | ポイント回収バッチ実行 |
| キャッシュクリア忘れ | 表示不具合 | 全キャッシュクリア実行 |

### 9.2 緊急時コマンド集

#### サービス再起動
```bash
# Netlify再デプロイ
netlify deploy --prod

# Supabaseサービス再起動
supabase db restart

# キャッシュ全クリア
curl -X POST https://ace-oripa.com/api/admin/cache/clear-all \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

#### ログ確認
```bash
# エラーログ確認
netlify logs --level=error

# アクセスログ確認
netlify logs --type=access

# DBスローログ確認
supabase db logs --slow-query
```

## 10. セキュリティ注意事項

### 10.1 アクセス管理

```markdown
必須ルール:
✅ 個人アカウントを使用
✅ 強力なパスワード（12文字以上）
✅ 2段階認証を有効化
✅ 定期的なパスワード変更（3ヶ月）
✅ 不要な権限は付与しない

禁止事項:
❌ パスワードの共有
❌ 公共WiFiでの管理画面アクセス
❌ ブラウザへのパスワード保存
❌ 作業後のログアウト忘れ
```

### 10.2 データ取り扱い

```markdown
機密データ:
- ユーザー個人情報
- 決済情報
- 売上データ
- システム設定値

取り扱いルール:
1. 業務目的以外での閲覧禁止
2. スクリーンショット最小限
3. データの外部持ち出し禁止
4. 不要なエクスポート禁止
5. アクセスログが記録される
```

### 10.3 インシデント発生時

```markdown
発見時の対応:
1. 即座に上長に報告
2. 証拠の保全（ログ、画面）
3. 影響範囲の特定
4. 一次対応の実施
5. 報告書の作成

連絡先:
- セキュリティ担当: security@aceoripa.com
```
