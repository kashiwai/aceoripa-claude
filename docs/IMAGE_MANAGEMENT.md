# カード画像管理ガイド

## 画像ファイルの配置場所

すべての画像ファイルは `/public/images/` フォルダに配置します。

```
/public/images/
├── ngcard.jpg          # デフォルトのカード画像
├── pokemon/            # ポケモンカード画像
│   ├── 003_アセロラ(エクバ) PSA10_PK-0003.jpg
│   ├── 008_マリオピカチュウ PSA10_PK-0008.jpg
│   └── ...
└── その他の画像ファイル
```

## 画像を入れ替える方法

### 方法1: 個別にカードの画像を変更

1. **管理画面から編集**
   - `/admin/cards` にアクセス
   - 変更したいカードの「編集」ボタンをクリック
   - 画像URLを直接入力または選択

2. **画像URLの形式**
   ```
   /images/ファイル名.jpg
   /images/pokemon/ファイル名.jpg
   ```

### 方法2: 一括で画像を更新

1. **CSVで一括更新**
   - CSVファイルに `product_code` と `image_url` を含める
   - インポート時に自動的に画像URLが設定される

2. **データベースで直接更新**
   ```sql
   UPDATE pokemon_cards 
   SET image_url = '/images/新しい画像.jpg' 
   WHERE card_name LIKE '%特定のカード名%';
   ```

### 方法3: プログラムで自動マッピング

カード名に基づいて自動的に画像を関連付けることができます：

```javascript
const IMAGE_MAPPING = {
  'アセロラ': '/images/pokemon/003_アセロラ(エクバ) PSA10_PK-0003.jpg',
  'マリオピカチュウ': '/images/pokemon/008_マリオピカチュウ PSA10_PK-0008.jpg',
  // ... 他のマッピング
}
```

## 新しい画像を追加する手順

1. **画像ファイルを準備**
   - 推奨サイズ: 300x420px (カードの縦横比)
   - 形式: JPG, PNG
   - ファイル名: 日本語も使用可能だが、英数字推奨

2. **ファイルをアップロード**
   - `/public/images/` または `/public/images/pokemon/` に配置
   - FTPやファイルマネージャーを使用

3. **データベースを更新**
   - 管理画面から個別に編集
   - または一括更新ツールを使用

## トラブルシューティング

### 画像が表示されない場合

1. **ファイルパスを確認**
   - パスが正しいか確認（大文字小文字に注意）
   - `/images/` で始まっているか確認

2. **ファイル形式を確認**
   - JPGファイルが破損していないか
   - 正しいJPEG形式か

3. **開発サーバーを再起動**
   ```bash
   npm run dev
   ```

### デフォルト画像を変更したい場合

`/images/ngcard.jpg` を新しい画像で置き換えるだけで、全体のデフォルト画像が変更されます。

## 推奨される運用フロー

1. **初期登録時**
   - CSVインポートでカードデータを一括登録
   - デフォルト画像（ngcard.jpg）が自動設定

2. **画像の準備ができたら**
   - 画像ファイルを適切なフォルダにアップロード
   - 管理画面から個別に画像URLを更新

3. **定期的なメンテナンス**
   - 使用されていない画像ファイルの削除
   - 画像URLの整合性チェック

## 便利なツール

- `/admin/cards/import` - CSVインポート（画像URL含む）
- `/admin/cards/[id]/edit` - 個別編集（画像URL変更）
- `/admin/cards/update-images` - 一括画像更新
