# ACEORIPA 管理画面マニュアル

## 1. ログイン方法

### アクセスURL
```
https://[your-domain]/admin
```

### ログイン手順
1. 管理者用メールアドレスを入力
2. パスワードを入力
3. 「ログイン」ボタンをクリック

※管理者権限（is_admin=true）が必要です

## 2. ダッシュボード

### 2.1 概要
ログイン後最初に表示される画面です。主要な指標が一覧できます。

### 2.2 表示項目
- **本日の売上**: 当日の売上金額
- **本日の注文数**: 当日の注文件数  
- **アクティブユーザー数**: 当日のログインユーザー数
- **在庫アラート**: 在庫が少ないカードの警告

## 3. ガチャ管理

### 3.1 ガチャ商品一覧
- 登録済みガチャ商品の一覧表示
- ステータス（公開/非公開）の確認
- 売上実績の確認

### 3.2 新規ガチャ作成
1. 「新規作成」ボタンをクリック
2. 基本情報入力:
   - **商品名**: ガチャの名前
   - **説明文**: ガチャの説明
   - **価格**: 必要ポイント数
   - **販売期間**: 開始日時・終了日時
3. 画像設定:
   - **バナー画像**: 1024×1024px推奨
   - **サムネイル**: 自動生成
4. 「保存」をクリック

### 3.3 カードプール設定
1. ガチャ商品の「プール設定」をクリック
2. カードを追加:
   - カード選択
   - 排出確率設定（%）
   - 在庫数設定
3. 確率合計が100%になるよう調整
4. 「保存」をクリック

### 3.4 ガチャ編集
1. 編集したいガチャの「編集」アイコンをクリック
2. 情報を修正
3. 「更新」をクリック

## 4. カード管理

### 4.1 カード一覧
- 登録済みカードの一覧
- レアリティ別フィルター
- 在庫数確認

### 4.2 カード個別登録
1. 「新規登録」をクリック
2. カード情報入力:
   - **カード名**: ポケモン名
   - **カード番号**: 001/165など
   - **レアリティ**: SS/S/A/B/C
   - **説明**: カードの説明文
3. 画像アップロード
4. 「登録」をクリック

### 4.3 CSV一括登録
1. 「CSVアップロード」タブを選択
2. テンプレートをダウンロード
3. CSVファイル作成:
   ```csv
   カード名,カード番号,レアリティ,説明,画像ファイル名
   ピカチュウ,025/165,S,でんきタイプの人気ポケモン,pikachu.jpg
   ```
4. ファイルを選択してアップロード
5. プレビュー確認
6. 「インポート実行」

### 4.4 画像管理
- 画像は`public/images/cards/`に配置
- 対応形式: JPG, PNG
- 推奨サイズ: 500×700px

## 5. ユーザー管理

### 5.1 ユーザー一覧
- 登録ユーザーの一覧表示
- 検索機能（メール、名前）
- ステータス確認

### 5.2 ユーザー詳細
- 基本情報
- ポイント残高
- 購入履歴
- 獲得カード一覧

### 5.3 ポイント調整
1. ユーザーの「詳細」をクリック
2. 「ポイント調整」ボタン
3. 追加/減算を選択
4. 金額と理由を入力
5. 「実行」をクリック

## 6. 売上・決済管理

### 6.1 決済一覧
- 決済履歴の確認
- ステータス別フィルター
- 期間指定検索

### 6.2 売上統計
- 日別/月別売上グラフ
- 商品別売上
- ユーザー別売上ランキング

### 6.3 返金処理
1. 該当決済を検索
2. 「返金」ボタンをクリック
3. 返金理由を入力
4. 「返金実行」をクリック

## 7. お知らせ管理

### 7.1 お知らせ作成
1. 「新規作成」をクリック
2. 内容入力:
   - **タイトル**: お知らせのタイトル
   - **本文**: お知らせ内容
   - **種類**: ニュース/メンテナンス/キャンペーン/重要
   - **公開期間**: 開始日時・終了日時
3. 表示設定:
   - **ポップアップ表示**: ON/OFF
   - **表示遅延**: 秒数指定
   - **画像**: バナー画像URL
   - **CTAボタン**: テキストとリンク先
4. 「公開」または「下書き保存」

### 7.2 お知らせ編集
- 公開中でも編集可能
- 履歴は自動保存

## 8. キャンペーン管理

### 8.1 キャンペーン作成
1. 基本情報:
   - キャンペーン名
   - 期間設定
   - 対象ユーザー
2. 特典設定:
   - ポイントボーナス
   - 確率アップ
   - 限定カード

### 8.2 効果測定
- 参加者数
- 売上影響
- ROI分析

## 9. AI生成機能

### 9.1 バナー生成
1. 「AI生成」→「バナー生成」
2. プロンプト入力:
   - ガチャテーマ
   - 雰囲気（クール/かわいい/迫力など）
   - 含めたい要素
3. 「生成」をクリック
4. 生成された画像から選択
5. 「使用する」をクリック

### 9.2 動画生成
1. 「AI生成」→「動画生成」
2. 設定:
   - 演出タイプ
   - 再生時間
   - BGM選択
3. 「生成開始」
4. プレビュー確認
5. 「採用」をクリック

## 10. システム設定

### 10.1 基本設定
- サイト名
- ロゴ
- お問い合わせ先

### 10.2 決済設定
- GMO fincode設定
- 手数料率
- 決済限度額

### 10.3 管理者設定
- 管理者アカウント追加
- 権限設定
- 操作ログ確認

## 11. ショートカットキー

- `Ctrl + S`: 保存
- `Ctrl + N`: 新規作成
- `Ctrl + F`: 検索
- `Esc`: キャンセル

## 12. 注意事項

### データ編集時
- 公開中のデータ編集は即座に反映されます
- 削除操作は取り消せません
- 大量データ操作時は事前バックアップ推奨

### セキュリティ
- 定期的なパスワード変更
- 共有PCでのログアウト徹底
- 不審なアクセスの報告
