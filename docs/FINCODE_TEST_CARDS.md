## テスト時の注意事項

1. **カード名義**: 任意の英字（例：TARO YAMADA）
2. **有効期限**: 現在より未来の年月を指定
3. **金額**: 50円以上で指定
4. **環境設定**: `.env.local`で`NEXT_PUBLIC_FINCODE_ENV=test`に設定

## 環境切り替え方法

### テスト環境を使用する場合
```env
NEXT_PUBLIC_FINCODE_PUBLIC_KEY=p_test_xxxxx
FINCODE_SECRET_KEY=m_test_xxxxx
NEXT_PUBLIC_FINCODE_ENV=test
```

### 本番環境を使用する場合
```env
NEXT_PUBLIC_FINCODE_PUBLIC_KEY=p_prod_xxxxx
FINCODE_SECRET_KEY=m_prod_xxxxx
NEXT_PUBLIC_FINCODE_ENV=prod
```
