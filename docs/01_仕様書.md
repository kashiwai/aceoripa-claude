# ACEORIPA システム仕様書

## 1. システム概要

### 1.1 プロジェクト名
ACEORIPA - ポケモンカード専門オンラインオリパサイト

### 1.2 技術スタック
- **フロントエンド**: Next.js 14.2.30 (App Router)
- **バックエンド**: Next.js API Routes
- **データベース**: Supabase (PostgreSQL)
- **認証**: Supabase Auth
- **決済**: GMO fincode
- **スタイリング**: Tailwind CSS
- **アニメーション**: Framer Motion
- **AI機能**: OpenAI API (GPT-4, DALL-E 3)

## 2. システムアーキテクチャ

### 2.1 フロントエンド構成
```
src/
├── app/                    # Next.js App Router
│   ├── page.tsx           # ホームページ
│   ├── gacha/             # ガチャ関連ページ
│   ├── mypage/            # マイページ
│   ├── payment/           # 決済ページ
│   ├── admin/             # 管理画面
│   └── api/               # APIエンドポイント
├── components/            # 再利用可能コンポーネント
├── lib/                   # ユーティリティ関数
└── hooks/                 # カスタムフック
```

### 2.2 データベース構成
- **users**: ユーザー情報
- **gacha_products**: ガチャ商品
- **cards**: カード情報
- **card_pools**: ガチャプール
- **gacha_results**: ガチャ結果
- **payment_orders**: 決済情報
- **announcements**: お知らせ
- **campaigns**: キャンペーン情報

## 3. 主要機能仕様

### 3.1 ユーザー機能
- **認証**: メール/パスワードログイン
- **ガチャ**: オンラインオリパ購入・実行
- **コレクション**: 獲得カード閲覧
- **ポイント**: ポイント購入・使用
- **お知らせ**: ポップアップ通知

### 3.2 ガチャシステム
- **レアリティ**: SS/S/A/B/C（5段階）
- **演出フロー**: 
  1. ガチャ実行
  2. アニメーション演出
  3. レアリティ告知
  4. カード公開
- **確率設定**: 管理画面から調整可能

### 3.3 決済システム
- **対応決済**: クレジットカード（GMO fincode）
- **ポイントパッケージ**: 
  - 1,000円 = 1,000pt
  - 3,000円 = 3,100pt
  - 5,000円 = 5,300pt
  - 10,000円 = 11,000pt

### 3.4 管理機能
- **ガチャ管理**: CRUD操作
- **カード管理**: CSV一括登録
- **ユーザー管理**: 一覧・編集
- **売上管理**: 決済履歴・統計
- **お知らせ管理**: ポップアップ配信
- **AI生成**: バナー・動画自動生成
