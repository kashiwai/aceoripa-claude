# 基本設計書 - Aceoripa オンラインガチャシステム

## 1. システム概要

### 1.1 システム名称
**Aceoripa（エースオリパ）** - ポケモンカード専用オンラインガチャプラットフォーム

### 1.2 システムの目的
- ポケモンカードコレクターに向けた革新的なオンラインガチャサービスの提供
- 市場価格連動型の公正で透明性の高いガチャシステムの実現
- 実物カードとデジタル体験を融合した新しいコレクション体験の創出

### 1.3 システムの特徴
1. **DOPA式ガチャシステム** - 実質還元率70%、体感還元率97%の革新的モデル
2. **市場カード戦略式** - リアルタイム市場価格連動の動的確率調整
3. **AI演出システム** - 感動的なガチャ演出による没入体験
4. **完全自動化運営** - 24時間365日の無人運営対応

## 6. セキュリティ設計

### 6.1 認証・認可
- **認証方式**: JWT + Supabase Auth
- **セッション管理**: HTTPOnly Cookie + Secure Flag
- **権限管理**: Role-Based Access Control (RBAC)
- **管理者認証**: 2段階認証推奨

### 6.2 データ保護
- **暗号化**: AES-256 (保存時), TLS 1.3 (通信時)
- **RLS**: Supabase Row Level Security
- **SQLインジェクション対策**: Prepared Statements
- **XSS対策**: Content Security Policy (CSP)

### 6.3 決済セキュリティ
- **PCI DSS準拠**: カード情報非保持
- **トークン化**: 決済情報のトークン化
- **3Dセキュア**: 本人認証サービス対応
- **不正検知**: 異常取引の自動検知

## 7. 運用設計

### 7.1 バックアップ
- **DB**: 日次自動バックアップ（30日保持）
- **ストレージ**: 週次バックアップ（90日保持）
- **設定ファイル**: Git管理 + 暗号化

### 7.2 監視項目
- **死活監視**: 1分間隔
- **パフォーマンス**: レスポンスタイム、CPU/メモリ使用率
- **エラー監視**: エラー率、例外発生

### 7.3 障害対応

- **自動復旧**: Auto-scaling, Self-healing
- **手動対応**: オンコール体制（24/7）
